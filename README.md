Tổng quan
Chuyển đổi tài liệu giữa các định dạng (DOCX, PDF, XLSX, PPTX, v.v.) trong Node.js hoặc browser sử dụng LibreOffice.
Các định dạng hỗ trợ 
Input: doc, docx, xls, xlsx, ppt, pptx, odt, ods, odp, rtf, txt, html, csv, pdf, epub
Output: pdf, docx, doc, odt, rtf, txt, html, xlsx, xls, ods, csv, pptx, ppt, odp, png, jpg, svg
Yêu cầu HTTP headers 
Cross-Origin-Opener-Policy: same-origin 
Cross-Origin-Embedder-Policy: require-corp
Yêu cầu hệ thống
Node.js 18.0.0
Dung lượng ~150 MB cho các tệp WASM
Browser: ~240 MB tải xuống ban đầu (cached after first load)
